# CareBridge AI

**An AI-Powered Patient Follow-Up and Care Coordination Assistant**

## Overview

CareBridge AI is a prototype designed to help users organise follow-up instructions from healthcare documents into a reviewable checklist.

## Features

- PDF text extraction
- Identification of possible follow-up instructions
- User confirmation before saving tasks
- Follow-up task tracking
- Pending, scheduled, and completed statuses

## Technology Stack

- Python
- Streamlit
- PyPDF
- LangChain and LangGraph (planned for AI workflow integration)

## Run Locally

1. Install Python.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## Safety Notice

This is an educational prototype. Use fictional data for demonstrations. It does not provide medical advice, diagnose conditions, or replace healthcare professionals.
